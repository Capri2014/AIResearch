# Daily Notes: 2026-03-20

## Pipeline PR #1: SSL Augmentations for Waymo Pretraining

### Summary
Added SSL-compatible augmentations (MoCo/SimCLR/Light) to the Waymo SSL pretraining pipeline, improving feature learning through temporal-consistent data augmentation.

### Changes

#### Created: `training/pretrain/augmentations.py`

**SSLAugmentationConfig**: Configurable augmentation parameters
- Spatial: crop_size, crop_scale, horizontal_flip
- Color: color_jitter, brightness, contrast, saturation, hue
- Blur: gaussian_blur, blur_prob, blur_kernel_size, blur_sigma
- Solarization: solarize, solarize_threshold, solarize_prob
- Grayscale: to_grayscale, grayscale_prob

**TemporalConsistentAugmentation**: Main class ensuring same augmentation for temporal pairs
- Applies identical transforms to anchor and positive frames
- Maintains temporal consistency which is critical for SSL

**Factory functions**:
- `build_ssl_augmentation(config, is_training)`: Generic SSL augmentation pipeline
- `build_moco_augmentation(crop_size)`: MoCo-style (strong color + blur + solarize)
- `build_simclr_augmentation(crop_size)`: SimCLR-style (strong color, weak spatial)
- `build_light_augmentation(crop_size)`: Light augmentation for faster training
- `build_inference_transform(crop_size)`: No augmentation for eval

**Helper classes**:
- `GaussianBlur`: Random Gaussian blur with configurable kernel/sigma
- `solarize`: Invert values above threshold

#### Modified: `training/pretrain/waymo_ssl_dataset.py`

- Added `augmentation` parameter to `WaymoTemporalPairDataset.__init__`
- Added augmentation application in `__getitem__`:
  - Loads anchor/positive images from paths
  - Applies temporal-consistent augmentation
  - Stores augmented images in output dict
- Added `augmentation` parameter to `create_waymo_ssl_dataloader`

#### Modified: `training/pretrain/train_waymo_ssl.py`

- Added `augmentation_type` config option (moco/simclr/light/none)
- Added `augment` boolean flag
- Added CLI args: `--augmentation-type`, `--no-augment`
- Integrated augmentation builder in `run_training`

### Usage
```bash
# Train with MoCo augmentation (default)
python -m training.pretrain.train_waymo_ssl \
    --episode-dir data/waymo_episodes \
    --augmentation-type moco \
    --num-steps 10000

# Train with SimCLR augmentation
python -m training.pretrain.train_waymo_ssl \
    --augmentation-type simclr \
    --num-steps 10000

# Light augmentation (faster)
python -m training.pretrain.train_waymo_ssl \
    --augmentation-type light \
    --num-steps 10000

# No augmentation
python -m training.pretrain.train_waymo_ssl \
    --augmentation-type none \
    --num-steps 10000

# Or disable with flag
python -m training.pretrain.train_waymo_ssl --no-augment
```

This enhancement improves the SSL pretraining (step 2) through better data augmentation, leading to better learned representations for downstream waypoint BC training.
