# Daily Notes: 2026-03-16

## Pipeline PR #1: E2E Pipeline Evaluation + Unified Checkpoint Manager

### Summary
Added end-to-end evaluation infrastructure and unified checkpoint management for the BC→RL pipeline. This bridges training checkpoints to CARLA evaluation.

### Changes

#### New File: `training/eval/e2e_pipeline_eval.py`
- **E2EEvalConfig**: Configuration dataclass for E2E evaluation
- **EndToEndPipelineEvaluator**: Main evaluator class
  - Loads BC checkpoint (WaypointBCModel)
  - Loads RL checkpoint (PPO delta-waypoint)
  - Runs CARLA scenarios with proper model integration
  - Outputs standardized metrics.json
- Supports dry-run mode when CARLA unavailable
- CLI: `--bc-checkpoint`, `--rl-checkpoint`, `--scenarios`, etc.

#### New File: `training/utils/checkpoint_manager.py`
- **CheckpointType**: Enum for checkpoint types (BC_WAYPOINT, RL_PPO_DELTA, etc.)
- **CheckpointInfo**: Dataclass for checkpoint metadata
- **CheckpointManager**: Unified loading interface
  - `inspect()`: View checkpoint without loading
  - `load_checkpoint()`: Auto-detect type and load
  - `detect_type()`: Automatic type detection from keys/config
- Supports BC waypoint, RL PPO/GRPO, SSL encoder checkpoints

### Usage
```bash
# Inspect checkpoint (without loading model)
python -m training.utils.checkpoint_manager out/ppo_delta_waypoint_2026_03_15/final.pt

# E2E evaluation with BC only
python -m training.eval.e2e_pipeline_eval \
    --bc-checkpoint out/waypoint_bc/final.pt \
    --scenarios straight_clear,turn_left_clear

# E2E evaluation with BC + RL
python -m training.eval.e2e_pipeline_eval \
    --bc-checkpoint out/waypoint_bc/final.pt \
    --rl-checkpoint out/ppo_delta_waypoint_2026_03_15/final.pt \
    --scenarios straight_clear,turn_left_clear
```
