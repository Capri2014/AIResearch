## Pipeline PR #4: SSL Encoder Integration + Waypoint Visualizer

### Summary
Integrated SSL encoder into WaypointBCModel forward pass and added waypoint visualization/diagnostics module.

### Changes

#### Updated: `training/bc/waypoint_bc_model.py`
- **SSL Encoder Integration:**
  - Added `ssl_encoder` and `freeze_ssl_encoder` parameters to WaypointBCModel
  - Added `ssl_projection` layer to map SSL embeddings to BEV feature space
  - Support direct `images=` input for SSL encoding path in forward()
  - New predict() method supports both bev_features and images inputs
- **Bug Fix:**
  - Fixed temporal encoding input dimension bug (was incorrectly multiplying by temporal_history)
- **Factory Updates:**
  - Added `use_temporal`, `temporal_history` parameters to create_waypoint_bc_model()
  - Added `freeze_ssl_encoder` and `ssl_encoder_checkpoint` parameters

#### Created: `training/bc/waypoint_visualizer.py`
- **WaypointVisualizer**: Visualization and diagnostics for waypoint predictions
  - `waypoints_to_image()`: Render waypoints as overhead BEV view
  - `visualize_prediction()`: Compare predicted vs target waypoints with color coding
  - `compute_metrics()`: ADE, FDE, and per-waypoint errors
  - `visualize_bev_features()`: Heatmap of BEV activation maps
- **Factory**: create_waypoint_visualizer()

#### Updated: `training/bc/__init__.py`
- Added exports for WaypointVisualizer, WaypointVisConfig, create_waypoint_visualizer

### Architecture
```
Images [B, 3, H, W]
       ↓
   SSL Encoder
       ↓
   ssl_projection (128 → 256)
       ↓
   MLP Heads → Waypoints [B, N, 2], Speeds [B, N]
```
