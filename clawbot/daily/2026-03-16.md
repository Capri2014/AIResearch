## Pipeline PR #1: E2E Pipeline Evaluation + Unified Checkpoint Manager

### Summary
Added end-to-end evaluation infrastructure and unified checkpoint management for the BC→RL pipeline. This bridges training checkpoints to CARLA evaluation.

### Changes

#### New File: `training/eval/e2e_pipeline_eval.py`
- **E2EEvalConfig**: Configuration dataclass for E2E evaluation
- **EndToEndPipelineEvaluator**: Main evaluator class
  - Loads BC checkpoint (WaypointBCModel)
  - Loads RL checkpoint (PPO delta-waypoint)
  - Runs CARLA scenarios with proper model integration
  - Outputs standardized metrics.json
- Supports dry-run mode when CARLA unavailable
- CLI: `--bc-checkpoint`, `--rl-checkpoint`, `--scenarios`, etc.

#### New File: `training/utils/checkpoint_manager.py`
- **CheckpointType**: Enum for checkpoint types (BC_WAYPOINT, RL_PPO_DELTA, etc.)
- **CheckpointInfo**: Dataclass for checkpoint metadata
- **CheckpointManager**: Unified loading interface
  - `inspect()`: View checkpoint without loading
  - `load_checkpoint()`: Auto-detect type and load
  - `detect_type()`: Automatic type detection from keys/config
- Supports BC waypoint, RL PPO/GRPO, SSL encoder checkpoints

### Usage
```bash

python -m training.utils.checkpoint_manager out/ppo_delta_waypoint_2026_03_15/final.pt
```

## Pipeline PR #2: Pipeline Inference Module

### Summary
Added a unified inference pipeline for BC → RL driving models. This provides a clean API for real-time inference, bridging trained checkpoints to CARLA integration and deployment.

### Changes

#### New File: `training/inference/pipeline_inference.py`
- **InferenceConfig**: Configuration dataclass for inference settings
  - Checkpoint paths (BC, RL, SSL)
  - Device, precision settings
  - Number of waypoints, confidence computation options
  
- **InferenceResult**: Result dataclass
  - BC waypoints, RL delta, final waypoints
  - Confidence scores (overall, BC-specific, RL-specific)
  - Inference timing metadata
  
- **PipelineInference**: Main inference class
  - `load_models()`: Load BC/RL/SSL checkpoints
  - `predict()`: Single observation inference
  - `predict_batch()`: Batch inference
  - `run_evaluation_suite()`: Scenario-based evaluation
  - Supports both BC-only and BC+RL modes

- **Convenience function**: `load_inference_pipeline()`

### Testing
- Import test: ✓
- Smoke test (dummy observation): ✓
  - Mode: bc_only
  - BC waypoints shape: (8, 2)
  - Final waypoints shape: (8, 2)
  - Confidence: 0.1

### Usage
```python
from training.inference.pipeline_inference import PipelineInference, InferenceConfig

# Load pipeline
config = InferenceConfig(
    bc_checkpoint="out/waypoint_bc/final.pt",
    rl_checkpoint="out/ppo_delta_waypoint_2026_03_15/final.pt",
)
inference = PipelineInference(config)

# Single inference
result = inference.predict(observation)
print(f"Waypoints: {result.final_waypoints}")
print(f"Confidence: {result.confidence}")

# Batch inference
results = inference.predict_batch(observations)
```
