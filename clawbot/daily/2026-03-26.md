# Daily Notes: 2026-03-26

## Pipeline PR #3: Unified CARLA Evaluation - Camera Sensor Integration

### What was done

**Updated: `training/eval/unified_carla_eval.py`**
- Added camera sensor integration for policy input
- Added `_setup_camera_sensor()`: RGB camera setup attached to ego vehicle
- Added `_cleanup_camera_sensor()`: Proper cleanup of camera resources
- Added `_get_camera_observation()`: Convert CARLA image to numpy array
- Modified `_run_carla_episode()` to setup/cleanup camera sensor
- Modified `_execute_episode_loop()` to use camera observations for policy inference
- Policy now receives camera images as input for waypoint prediction
- Falls back to random baseline when no camera data available

### New Methods Added
- `_setup_camera_sensor(vehicle)`: Spawns RGB camera at front windshield position (640x360, 110° FOV)
- `_cleanup_camera_sensor()`: Stops listening and destroys sensor
- `_get_camera_observation()`: Converts CARLA image to RGB numpy array (H, W, 3)

### Camera Configuration
- Resolution: 640x360
- FOV: 110°
- Position: Front windshield (x=1.5, y=0.0, z=1.4)
- Format: RGBA → RGB conversion

### Usage (same as before)
