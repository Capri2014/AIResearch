## Pipeline PR #5: RL Refinement After SFT - Delta Waypoint Learning

### What was done

**Created: `training/rl/ppo_delta_waypoint_learning.py`** - RL after SFT implementation
- `SFTWaypointModel`: SFT model that predicts base waypoints from state (can load from checkpoint)
- `ResidualDeltaHead`: Small delta head that learns corrections to SFT base waypoints
- `RLAfterSFTActor`: Combined actor = SFT_base + delta (SFT frozen during RL training)
- `ToyKinematicWaypointEnv`: 2D kinematic car environment that consumes predicted waypoints
- `PPOAgent`: PPO agent for delta-waypoint learning with value function

**Key Architecture (Option B - Waypoint Deltas):**
```
final_waypoints = sft_base_waypoints + delta_head(state)
```
- Action space = waypoint deltas (not raw controls)
- SFT model stays frozen; only delta head is trained
- Can initialize from trained BC checkpoint via SFT model loading

**Training Results (50 episodes):**
- Episode 10: avg_reward=206.31, success=100%
- Episode 30: avg_reward=338.93, success=100%
- Episode 50: avg_reward=139.79, success=50%
- Final success rate (last 10): 50%

### Artifacts Created
- `out/rl_after_sft_20260326_193548/metrics.json` - Full training metrics
- `out/rl_after_sft_20260326_193548/train_metrics.json` - Training summary
- `out/rl_after_sft_20260326_193548/checkpoint_final.pt` - Model checkpoint

### Key Components
1. **ToyKinematicWaypointEnv**: Kinematic car (bicycle model) in 2D world
   - State: [x, y, heading, speed, goal_x, goal_y]
   - Action: delta waypoints (8 waypoints x 2 coordinates)
   - Reward: progress + time penalty + goal completion

2. **RLAfterSFTActor**: Residual learning architecture
   - SFT model predicts base waypoints (frozen)
   - Delta head predicts corrections
   - Final = base + delta

3. **PPO Training**: Standard PPO with value function
   - Learns to predict better deltas
   - Optimizes for driving metrics (progress, success)
