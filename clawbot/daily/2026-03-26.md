# Daily Notes: 2026-03-26

## Pipeline PR #1: Unified CARLA Evaluation Pipeline

### What was done

**Created: `training/eval/unified_carla_eval.py`**
- Comprehensive evaluation pipeline for BC, RL, and SFT+Delta policies
- Multi-weather support: clear, cloudy, night, rain
- Auto-detection of latest BC/RL checkpoints (`find_latest_bc_checkpoint()`, `find_latest_rl_checkpoint()`)
- PolicyLoader class for loading different policy types
- EpisodeMetrics and AggregateMetrics dataclasses
- Dry-run mode for testing without CARLA connection

### Features
- `EvalConfig`: Configuration dataclass for all evaluation settings
- `PolicyLoader`: Supports bc, rl, and sft_delta policy types
- Weather-specific result files (`weather_clear.json`, etc.)
- Comprehensive metrics: route_completion, collisions, offroad, ADE, FDE
- Support for ScenarioRunner integration (`--use-srunner`)

### Usage

```bash
# Dry-run (always works)
python3 -m training.eval.unified_carla_eval --dry-run

# Full evaluation with multiple weather conditions
python3 -m training.eval.unified_carla_eval \
    --weather clear,cloudy,night,rain \
    --num-episodes 10

# Auto-detect latest BC checkpoint
python3 -m training.eval.unified_carla_eval \
    --auto-detect --policy-type bc \
    --weather clear,cloudy

# Evaluate specific checkpoint
python3 -m training.eval.unified_carla_eval \
    --checkpoint out/waypoint_bc/final.pt \
    --policy-type bc
```
