## Pipeline PR #1: CARLA Route Manager

### Summary
Added CARLA Route Manager for defining and managing driving routes for CARLA evaluation. This bridges the waypoint BC policies with CARLA ScenarioRunner integration.

### Changes

#### Created: `training/rl/carla_route_manager.py`

**RouteWaypoint**: Single waypoint along a route
- Position (x, y, z) and orientation (pitch, yaw, roll)
- Road/lane IDs
- Distance to goal tracking
- Conversion to CARLA transform

**DrivingRoute**: Complete driving route
- Start/end waypoints
- Intermediate waypoints list
- Total length calculation
- Difficulty rating (easy/medium/hard)
- Serialization support

**CARLARouteManager**: Route management
- Predefined routes for Town01, Town02, Town03
- Route filtering by difficulty
- Route retrieval by name
- JSON serialization/deserialization
- Custom route addition

**WaypointBCEvaluationRouteAdapter**: Bridge to waypoint BC
- Converts DrivingRoute to BC input format
- Extracts goal/start positions for BC model

**Helper functions**:
- `generate_interpolated_route()`: Simple route between two points

## Pipeline PR #3: Waypoint BC with SSL Encoder Transfer Learning

### Summary
Implemented waypoint BC training with SSL encoder transfer learning, bridging PR #2 (SSL pretrain) to the BC training phase.

### Changes

#### Created: `training/bc/train_waypoint_bc_ssl.py`

**WaypointBCWithSSLDataset**: Dataset that combines Waymo episodes with SSL encoder features
- Loads camera images from episodes
- Passes through SSL encoder to get BEV features
- Returns encoded features + waypoints for BC training
- Supports stub data for testing without real episodes

**WaypointMLPHead**: MLP head for waypoint prediction
- 3-layer MLP: in_dim → 256 → 256 → horizon*2
- Outputs (B, horizon_steps, 2) waypoint coordinates

**create_stub_ssl_encoder()**: Creates encoder for testing without pretrained weights
- Useful for debugging pipeline without SSL pretraining

**load_ssl_encoder()**: Loads pretrained SSL encoder from checkpoint
- Returns (config, encoder) tuple
- Handles multiple checkpoint formats

**WaypointBCTraining**: Full training loop
- Mixed precision (AMP) support
- Checkpoint saving every N steps
- Cosine annealing LR scheduler
- L2 (MSE) loss for waypoint prediction

## Pipeline PR #4: BC+SSL to RL Refinement Integration

### Summary
Integrated BC waypoint model with RL refinement training using PPO. This connects the BC+SSL checkpoint to the RL training loop for delta-waypoint refinement.

### Changes

#### Created: `training/rl/bc_ssl_rl_refinement.py`

**BCWaypointPredictor**: BC model for base waypoint predictions
- Loads from BC+SSL checkpoint
- Predicts waypoints from BEV features (or stub for testing)

**SSLEncoderWrapper**: SSL encoder wrapper
- Extracts features from SSL pretrained encoder
- Projects to BEV feature dimension

**DeltaWaypointRefinement**: PPO network for delta refinement
- Actor network: state → delta waypoints (16 dims for 8 waypoints)
- Critic network: state → value estimate
- Learnable log_std for exploration

**BCWaypointEnvWrapper**: Environment wrapper
- Combines BC base waypoints with delta refinement
- Applies deltas to BC predictions and steps environment

**BCSSLRefinementTrainer**: Full training loop
- PPO with GAE advantages
- Checkpoint saving
- Metrics tracking
- Evaluation at intervals

**PPOAgent**: PPO policy update
- Clipped surrogate objective
- Value and entropy losses
- GAE advantage computation
