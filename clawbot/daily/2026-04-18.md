# Pipeline PR #3 (2026-04-18): Pipeline Execution Runner

**Date**: 2026-04-18 10:30am PT  
**Theme**: Orchestrate end-to-end pipeline runs with stage management

---

## Summary

Created PipelineExecutionRunner to orchestrate the full driving-first pipeline (SSL → BC → RL → Eval) with single entry point, checkpoint passing, and metadata tracking.

---

## Created/Modified Files

### 1. Pipeline Execution Runner

**Created: `training/pipeline_execution_runner.py`**

- PipelineExecutionConfig: Run configuration (run_id, stages, output_dir, epochs/iterations)
- PipelineExecutionRunner: Main orchestrator class
- StageResult: Per-stage execution result with timing/checkpoint/metrics
- PipelineExecutionResult: Full pipeline result with summary
- Stage execution: _run_stage() with subprocess execution and timeout
- Checkpoint passing: _find_checkpoint() locates stage outputs for next stage
- Metadata tracking: _save_metadata() writes run metadata to JSON
- Dry-run mode: --dry-run prints commands without executing
- CLI: --run-full, --stage (ssl|bc|rl|eval), --resume, --output-dir

**Smoke test**: ✅ PASSED
- Dry run completed for all 4 stages
- SSL → BC → RL → Eval command chain verified
- Metadata saved to out/pipeline_20260418_133403_metadata.json

---

## Usage

```bash
# Run full pipeline (dry-run)
python training/pipeline_execution_runner.py --run-full --dry-run

# Run full pipeline (actual execution)
python training/pipeline_execution_runner.py --run-full

# Run single stage
python training/pipeline_execution_runner.py --stage ssl --episodes-glob "data/waymo/*.zarr"

# Custom run ID and output
python training/pipeline_execution_runner.py --run-full --run-id my_run_001 --output-dir out
```
