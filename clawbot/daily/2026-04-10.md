- **Created: `sim/driving/carla_srunner/evaluate.py`**
  - Closed-loop evaluation harness integrating runner.py + policy_wrapper.py
  - Bridges policy inference with CARLA ScenarioRunner metrics collection
  - Aggregates metrics across scenario suites

- **Key additions:**
  - `EvalRunConfig`: dataclass for evaluation run configuration
  - `ScenarioResult`: result from single scenario (success, route_completion, infractions)
  - `EvalMetrics`: aggregated evaluation metrics
  - `run_single_scenario()`: run single scenario with policy and collect metrics
  - `run_suite_evaluation()`: batch evaluate all scenarios in a suite
  - `parse_srunner_output()`: parse ScenarioRunner logs for metrics
  - `save_metrics()`: save metrics + scenario_results + config to JSON
  - `print_summary()`: pretty-print evaluation summary

- **CLI:**
  - `--checkpoint <path>`: trained model checkpoint
  - `--suite <name>`: scenario suite to run (smoke, weather, full)
  - `--scenario <id>`: single scenario
  - `--carla-host/--carla-port`: CARLA connection
  - `--timeout`: per-scenario timeout (default 300s)
  - `--list-scenarios`, `--list-suites`: list options
  - Output: `out/eval/<run_id>/metrics.json`, `scenario_results.json`, `config.json`

- **Updated: `sim/driving/carla_srunner/__init__.py`**
