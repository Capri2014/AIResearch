## Pipeline PR #5: RL Refinement After SFT - Delta Waypoint Learning

### Summary
Enhanced the RL after SFT (delta waypoint learning) implementation with checkpoint loading stubs, bounded deltas, comfort metrics, and trajectory tracking. This completes the Option B action space implementation for the driving-first pipeline.

### Changes

**Updated: `training/rl/ppo_delta_waypoint_learning.py`**

1. **Bounded delta head:**
   - Added `tanh * delta_bound` to prevent extreme corrections
   - Configurable via `--delta-bound` (default 5.0)

2. **Checkpoint loading stub:**
   - Added `SFTWaypointModel.from_BC_checkpoint()` class method
   - Supports loading from trained BC checkpoint
   - Handles various checkpoint formats (model_state_dict, state_dict)

3. **Enhanced reward shaping:**
   - Added `progress_scale`, `time_penalty`, `goal_reward`, `timeout_penalty`, `collision_penalty`
   - Added comfort penalty (max_accel_threshold)

4. **Per-step trajectory tracking:**
   - Added `position_history`, `speed_history`, `acceleration_history`
   - Added `get_comfort_metrics()`: max_acceleration, max_jerk

5. **Metrics schema compliance:**
   - Added `domain='rl'` to metrics.json
   - Added `action_space='waypoint_deltas'` to config
   - Added comfort to train_metrics.json

6. **CLI enhancements:**
   - Added `--sft-checkpoint`, `--bc-checkpoint`, `--delta-bound` args
