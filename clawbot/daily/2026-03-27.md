## Pipeline PR #2: Enhanced Metric Tracking for Unified CARLA Eval

### Summary
Added enhanced metric tracking with per-step trajectory analysis, violation tracking for stop signs/lanes, and comfort metrics aggregation. This enables more granular evaluation and debugging of driving policies.

### Changes

**Updated: `training/eval/unified_carla_eval.py`**

1. **EpisodeMetrics enhancements:**
   - Added `stop_sign_violations`, `collision_severity`, `lane_violations` fields
   - Added optional per-step trajectories: `step_rewards`, `step_speeds` (for trajectory analysis)
   
2. **New StepMetrics dataclass:**
   - Per-step tracking: speed, acceleration, jerk, distance_to_goal, reward
   - Violation flags: collision, red_light, stop_sign, offroad, lane_violation
   
3. **New EpisodeTracker class:**
   - Track step-by-step metrics during episode execution
   - `add_step()`: Add metrics at each timestep
   - `mark_violation()`: Mark violations during execution
   - `get_max_acceleration()`, `get_max_jerk()`: Aggregate comfort metrics
   - `compute_ade_fde()`: Trajectory-level ADE/FDE computation
   
4. **AggregateMetrics enhancements:**
   - Added violation aggregates: mean_red_light_violations, mean_stop_sign_violations, mean_lane_violations, mean_collision_severity
   - Added comfort metrics: mean_max_acceleration, mean_max_jerk
   
5. **Enhanced dry-run simulation:**
   - Simulates realistic stop_sign_violations, lane_violations, collision_severity
   
6. **Enhanced summary output:**
   - Displays violation breakdown and comfort metrics

## Pipeline PR #3: Waymo Episode Loader for SSL Pretraining

### Summary
Added Waymo episode loader module for loading episodes and converting to SSL pretraining format. This bridges the first stage of the driving-first pipeline (Waymo episodes → SSL pretrain).

### Changes

**Created: `AIResearch/training/episodes/waymo_episode_loader.py`**

1. **Data classes:**
   - `Pose`: 3D pose (position + rotation)
   - `Waypoint`: Single waypoint with position/velocity/acceleration
   - `CameraFrame`: Camera frame with intrinsics/extrinsics
   - `WaymoRoute`: Route with waypoints
   - `WaymoEpisode`: Episode container with routes, logs, frames

2. **WaymoEpisodeLoader class:**
   - Supports stub episodes (data/stub_episodes/), synthetic, and Waymo formats
   - `list_episodes()`: List available episode files
   - `load_episode()`: Load single episode
   - `load_episodes()`: Load multiple episodes
   - `to_ssl_dataset()`: Convert to SSL pretraining format
   - `get_statistics()`: Dataset stats (locations, weathers)

3. **CLI interface:**
   - `--list`: List available episodes
   - `--stats`: Show dataset statistics
   - `--max-episodes N`: Limit episodes to load
