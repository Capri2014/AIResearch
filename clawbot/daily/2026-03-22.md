## Pipeline PR #5: PPO Delta-Waypoint Training for RL After SFT

### Summary
Added PPO training script for residual delta-waypoint learning after SFT. This demonstrates Option B from the RL-after-SFT roadmap where the action space is waypoint deltas and the SFT model stays frozen while a delta head learns corrections.

### Changes

#### New File: `training/rl/run_ppo_delta_waypoint_daily.py`
- **ResidualDeltaHead**: Small MLP that predicts delta corrections to waypoints
- **SFTWaypointModelStub**: Stub SFT model that generates baseline waypoints from car state
- **PPODeltaPolicy**: PPO policy with delta head and value head
- **train_ppo_delta_waypoint()**: Complete training loop with rollout collection, GAE advantages, PPO updates

Key features:
- Option B: Action space = waypoint deltas
- final_waypoints = sft_waypoints + delta_head(z)
- Only delta head is trainable; SFT model frozen
- GAE-based advantage estimation
- Checkpointing and metrics logging

#### Training Results (50 episodes)
- Final avg reward (last 10): -5.04
- Episode lengths: 200 (max - environment truncates)
- Training improves over baseline

### Artifacts Generated
- `out/ppo_delta_daily_2026_03_22/run_20260322_193449/`:
  - `metrics.json` - Per-eval-interval metrics
  - `train_metrics.json` - Full training history
  - `checkpoints/checkpoint_50.pt` - Model checkpoint
  - `final.pt` - Final model

### Usage
```bash
# Run PPO delta-waypoint training
python -m training.rl.run_ppo_delta_waypoint_daily \
    --out-dir out/ppo_delta_daily_2026_03_22 \
    --episodes 50 \
    --seed 42

# With SFT checkpoint initialization
python -m training.rl.run_ppo_delta_waypoint_daily \
    --sft-checkpoint out/waypoint_bc/run_20260312_083423/final_checkpoint.pt \
    --out-dir out/ppo_delta_from_bc \
    --episodes 100
```

## Pipeline PR #3: BEV SSL GRPO Refinement

### Summary
Added GRPO (Group Relative Policy Optimization) refinement for the BEV SSL waypoint BC model. This is the RL refinement step in the driving-first pipeline that takes the BC model and trains a delta head to improve upon it via RL.

### Changes

#### New File: `training/rl/bev_ssl_grpo_refinement.py`
- **BEVSSLGRPOConfig**: Configuration dataclass for BEV SSL GRPO
- **BEVSSLDeltaWaypointHead**: Small delta prediction head for RL refinement
- **BEVSSLGRPOAgent**: Combined BC + delta model for GRPO training
- **WaypointRefinementEnv**: Environment wrapper for waypoint RL training
- **BEVSSLGRPOTrainer**: Complete training loop with GRPO optimization

Key features:
- Keeps BC model frozen, trains delta head only
- Three fusion methods: concat, attention, add
- GRPO loss with group-relative advantage scoring
- KL penalty for stable training
- Checkpointing and metrics logging

#### New File: `training/rl/test_bev_ssl_grpo_refinement.py`
- Smoke test for BEV SSL GRPO refinement module
- Tests config, delta head, agent forward pass

## Pipeline PR #2: Waypoint BC with BEV SSL Encoder Transfer Learning

### Summary
Added waypoint behavior cloning (BC) training that leverages the BEV SSL encoder from Pipeline PR #1. The BEV encoder transforms multi-camera + LiDAR data into unified BEV features, which are then used for waypoint prediction.

### Changes

#### New File: `training/bc/bev_ssl_waypoint_bc.py`
- **WaypointBCWithBEVSSLDataset**: Dataset wrapper that combines Waymo episodes with BEV SSL encoder
- **WaypointBCWithBEVSSLTrainer**: Complete training loop with mixed precision and checkpointing
- **create_bev_ssl_waypoint_bc_model()**: Factory function to create BC model with BEV encoder
- **bev_ssl_waypoint_bc_training_loop()**: End-to-end training function with CLI

Key features:
- Three fusion methods supported: concat, attention, add
- Transfer learning from BEV SSL checkpoint (optional)
- Freeze BEV encoder or fine-tune (configurable)
- Mixed precision training (AMP)
- Checkpointing and metrics logging

- Added WaypointBCWithBEVSSLTrainer exports
- Added create_bev_ssl_waypoint_bc_model exports

## Pipeline PR #1: BEV SSL Pretraining for Waymo Data

### Summary
Added BEV (Bird's Eye View) SSL pretraining with temporal contrastive learning and cross-modal camera-LiDAR alignment.

### Changes

#### New File: `training/pretrain/bev_encoder.py`
- **BEVConfig**: Configuration dataclass for BEV encoder
- **ConvBlock**: Basic conv block with BN + ReLU
- **CameraEncoder**: Multi-camera image encoder (6 cameras → 128D features)
- **LidarEncoder**: LiDAR to BEV projection encoder
- **CrossViewAttention**: Attention-based camera-LiDAR fusion
- **BEVEncoder**: Complete BEV encoder with three fusion methods:
  - `concat`: Concatenate + MLP
  - `attention`: Cross-view attention
  - `add`: Simple addition

#### New File: `training/pretrain/bev_ssl_pretrain.py`
- **BEVSSLConfig**: Configuration for BEV SSL training
- **bevQueue**: Queue for negative samples in contrastive learning
- **TemporalContrastiveLoss**: InfoNCE-style temporal contrastive loss
- **CrossModalAlignmentLoss**: Align camera and LiDAR features
- **WaymoBEVDataset**: Dataset for BEV SSL pretraining
- **BEVSSLTrainer**: Complete training loop with:
  - Query encoder (trained via backprop)
  - Key encoder (momentum updated)
  - Queue management
  - Temporal + alignment losses

#### Updated: `training/pretrain/__init__.py`
- Added BEVEncoder, BEVConfig, create_bev_encoder exports
- Added BEVSSLConfig, BEVSSLTrainer, bev_ssl_training_loop exports
