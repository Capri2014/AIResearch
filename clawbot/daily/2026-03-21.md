# Daily Log - 2026-03-21

## Pipeline PR #1 (2026-03-21): MoCo SSL + Unified Inference Pipeline

### Summary
Added MoCo-style self-supervised pretraining and unified BC+RL inference pipeline.

### Changes

#### New File: `training/pretrain/moco_waymo_ssl.py`
- **MoCoEncoder**: Momentum contrastive encoder with query/key encoders
  - Query encoder (q_enc): trained via backprop
  - Key encoder (k_enc): updated via EMA from q_enc
  - Shuffled BN for preventing shortcut learning
- **MoCoQueue**: Queue management for negative sample storage
  - FIFO queue with configurable size (default: 65536)
  - Momentum-based enqueue/dequeue
- **moco_training_loop()**: Full MoCo training loop
  - Queue-based contrastive loss (InfoNCE)
  - Momentum update (m=0.999 default)
  - Checkpoint saving with metadata

#### New File: `training/inference/pipeline_inference.py`
- **InferenceConfig**: Configuration for inference pipeline
  - BC, RL, SSL checkpoint paths
  - Device, precision, waypoint settings
  - Output directory configuration
- **InferenceResult**: Result dataclass with:
  - bc_waypoints, final_waypoints, rl_delta
  - Confidence scores (bc_confidence, rl_confidence)
  - Inference timing and mode tracking
- **PipelineInference**: Unified BC+RL inference
  - BC-only mode: direct waypoint prediction
  - BC+RL mode: waypoint + delta refinement
  - Batch inference support

#### Updated: `training/pretrain/__init__.py`
- Added MoCoEncoder, MoCoQueue, load_moco_checkpoint exports

### Usage
```bash
# Run MoCo SSL pretraining
python -m training.pretrain.moco_waymo_ssl \
    --episode-dir data/waymo_episodes \
    --batch-size 32 \
    --num-steps 10000 \
    --moco-m 0.999 \
    --queue-size 65536

# Run inference
from training.inference.pipeline_inference import PipelineInference, InferenceConfig

config = InferenceConfig(
    bc_checkpoint="out/waypoint_bc/final.pt",
    rl_checkpoint="out/ppo_delta_waypoint/model.pt",
)
inference = PipelineInference(config)
result = inference.predict(observation)
```
