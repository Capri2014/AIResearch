## Pipeline PR #2 (7:30am PT) — Temporal Masked Prediction (TMP) Objective

### What changed

- **Created `training/pretrain/temporal_masked_objective.py`**
  - Temporal Masked Prediction (TMP) objective for SSL pretraining
  - Complements contrastive learning with future prediction
  - Predicts future encoder embeddings from past context

- **Components:**
  - `TMPConfig`: Configuration dataclass
  - `TemporalPredictor`: LSTM-based predictor for temporal sequences
  - `TemporalMaskedPredictor`: Transformer-based predictor
  - `TMPObjective`: Main module integrating with SSL training
  - `compute_tmp_loss`: MSE + alignment loss
  - `CombinedSSLLoss`: Combined loss (contrastive + waypoint + TMP)

- **Architecture:**
  - Takes encoder embeddings over time
  - Uses context_length past timesteps to predict predict_horizon future timesteps
  - Two predictor variants: LSTM (lightweight) or Transformer (expressive)
  - Loss: MSE + cosine alignment

### Integration

To enable TMP in run_ssl_pretrain:
```python
from training.pretrain.temporal_masked_objective import TMPConfig, TMPObjective
config = TMPConfig(predict_horizon=5, context_length=10, weight=0.5)
tmp = TMPObjective(encoder_dim=512, config=config)
# In training loop:
loss, info = tmp(encoder_embeds)  # encoder_embeds: (B, T, D)
```

### Purpose

Pipeline stage 2: Waymo → **SSL pretrain** → waypoint BC → RL → CARLA

TMP adds temporal understanding beyond contrastive/waypoint:
- Contrastive: cross-view alignment (spatial multi-camera)
- Waypoint: per-timestep prediction
- **TMP: temporal future prediction (what happens next)**

This helps the encoder learn temporal dynamics for better downstream BC.
