## Pipeline PR #1: BEV SSL Pretraining with Learning Rate Scheduling & Checkpointing

### Summary
Added learning rate scheduling (cosine annealing with warm restarts, step decay), gradient clipping, and robust checkpoint management to the BEV SSL pretraining pipeline for more stable and resumable training.

### Changes

#### Updated: `training/pretrain/bev_ssl_pretrain_aug.py`

- **Enhanced BEVSSLConfig**:
  - Added `scheduler: str` - Choose between "cosine", "step", or "none"
  - Added `lr_warmup_epochs: int` - Warmup epochs before main scheduler
  - Added `lr_decay_factor: float` - Decay factor for step scheduler
  - Added `lr_decay_epochs: List[int]` - Milestones for step scheduler
  - Added `min_learning_rate: float` - Minimum LR for cosine scheduler
  - Added `grad_clip: Optional[float]` - Gradient clipping value
  - Added `save_interval: int` - Save checkpoint every N epochs
  - Added `keep_last_n_checkpoints: int` - Number of recent checkpoints to keep
  - Added `resume_from: Optional[str]` - Resume training from checkpoint

- **Enhanced BEVSSLTrainer**:
  - Added `_create_scheduler()` - Creates LR scheduler based on config
  - Added `_save_checkpoint()` - Saves model, optimizer, scheduler, queue state
  - Added `_cleanup_old_checkpoints()` - Removes old checkpoints, keeps only N most recent
  - Added `_load_checkpoint()` - Loads checkpoint to resume training
  - Added `get_current_lr()` - Returns current learning rate
  - Added gradient clipping in `train_step()`
  - Updated `train()` with scheduler step, checkpointing, and metrics logging

- **Updated CLI** (`if __name__ == "__main__"`):
  - Added `--scheduler` argument
  - Added `--warmup-epochs` argument
  - Added `--grad-clip` argument
  - Added `--save-interval` argument
  - Added `--keep-checkpoints` argument
  - Added `--resume` argument

### Usage
```bash
# Run BEV SSL with cosine annealing (default)
python -m training.pretrain.bev_ssl_pretrain_aug \
    --episode-dir data/waymo_episodes \
    --batch-size 32 \
    --num-epochs 100 \
    --output-dir out/bev_ssl \
    --scheduler cosine \
    --warmup-epochs 5 \
    --grad-clip 1.0 \
    --save-interval 10

# Run with step decay
python -m training.pretrain.bev_ssl_pretrain_aug \
    --episode-dir data/waymo_episodes \
    --scheduler step \
    --lr-decay-epochs 30 60 90 \
    --lr-decay-factor 0.1

# Resume training from checkpoint
python -m training.pretrain.bev_ssl_pretrain_aug \
    --resume out/bev_ssl/checkpoints/latest.pt
```

### Checkpoint Structure
Checkpoints are saved to `out/bev_ssl/checkpoints/`:
- `latest.pt` - Always the most recent checkpoint
- `epoch_XXX.pt` - Epoch-specific checkpoints
- `best.pt` - Best model based on validation loss
- `training_metrics.json` - Full training metrics history

Each checkpoint contains:
- Query encoder state
- Key encoder state  
- Optimizer state
- Scheduler state
- Queue state
- Metrics history
- Config

## Pipeline PR #2: Waypoint Prediction Head for BEV SSL Encoder

### Summary
Added waypoint prediction head that connects the pretrained BEV SSL encoder to waypoint BC training, enabling transfer learning from SSL pretraining to trajectory prediction.

### Changes

#### Created: `training/bc/bev_ssl_waypoint_predictor.py`
- **WaypointPredictionHead**: MLP head taking BEV features → waypoints
- **BEVSSLWaypointPredictor**: Combined encoder + waypoint head model
- **WaypointBCLoss**: Combined waypoint L1 + speed classification loss
- **WaypointPredictorTrainer**: Full training loop with LR scheduling/checkpointing
- **create_waypoint_predictor()**: Factory to load from SSL checkpoint
- **load_bev_encoder_from_checkpoint()**: Load encoder weights from SSL checkpoint
- **WaypointHeadConfig**: Configuration dataclass

- Tests for all components
