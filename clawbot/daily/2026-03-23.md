## Pipeline PR #1: BEV SSL Pretraining for Waymo Data

### Summary
Added BEV-specific augmentations to complement image-based augmentations for more robust self-supervised learning of BEV representations.

### Changes

#### New File: `training/pretrain/bev_augmentations.py`
- **BEVAugmentationConfig**: Configuration dataclass for all BEV augmentations
- **BEVSpatialAugmentation**: Spatial transforms (flip, rotation, scale, crop)
- **BEVOcclusionAugmentation**: Occlusion/dropout for robustness
- **BEVNoiseAugmentation**: Gaussian and uniform noise
- **BEVTemporalAugmentation**: Temporal frame dropping
- **BEVAugmentation**: Combined pipeline with unified interface
- **build_bev_augmentation()**: Factory function
- **bev_collate_fn()**: Custom collate for dataloaders

#### Updated: `training/pretrain/__init__.py`
- Added BEVAugmentationConfig, BEVAugmentation, build_bev_augmentation exports

### Usage
```python
from training.pretrain.bev_augmentations import (
    BEVAugmentationConfig,
    build_bev_augmentation,
)

# Configure augmentations
config = BEVAugmentationConfig(
    random_crop=True,
    horizontal_flip=True,
    random_rotation=True,
    max_rotation_deg=15.0,
    random_mask=True,
    mask_prob=0.3,
    add_gaussian_noise=True,
    noise_std=0.01,
)

# Build augmentation pipeline
aug = build_bev_augmentation(config, is_training=True)

# Apply to BEV features
bev = torch.randn(128, 200, 200)  # (C, H, W)
temporal_bev = torch.randn(3, 128, 200, 200)  # (T, C, H, W)
aug_bev, aug_temporal = aug(bev, temporal_bev)
```
