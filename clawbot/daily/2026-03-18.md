# Daily Notes: 2026-03-18

## Pipeline PR #1: Traffic-Aware Waypoint Environment

### Summary
Added traffic-aware waypoint environment that extends the kinematic environment with dynamic traffic obstacles, bridging the gap between simple kinematic training and real CARLA scenarios.

### Changes

#### Created: `training/rl/traffic_aware_waypoint_env.py`

**TrafficVehicle**: Dynamic traffic vehicle class
- Path-following behavior along predefined waypoints
- Position, heading, speed tracking
- Update method for kinematic movement

**TrafficAwareWaypointConfig**: Extended configuration
- Traffic density levels: NONE, LOW, MEDIUM, HIGH
- Number of static/dynamic obstacles
- Traffic speed range and spawn margins
- Collision and near-collision penalties

**Traffic Generators**:
- `generate_straight_traffic()`: Same/opposite direction traffic
- `generate_cross_traffic()`: Intersecting traffic
- `generate_turn_traffic()`: Turning vehicles at intersections
- `generate_static_obstacles()`: Static obstacle placement

**Collision Detection**:
- `check_collision()`: Circle-based collision between vehicles
- `check_near_collision()`: Proximity detection

**TrafficAwareWaypointEnv**: Main environment class
- Extends KinematicWaypointEnv with traffic
- State includes ego vehicle + traffic positions + obstacles
- Traffic-aware rewards: collision penalty, near-collision penalty
- Supports all traffic density levels

**RL Training**:
- `train_traffic_aware()`: Training loop with simple MLP policy
- Policy gradient updates
- Tracks success rate, collision rate

### Usage
```bash
# Smoke test
python -m training.rl.traffic_aware_waypoint_env --test

# Train with low traffic
python -m training.rl.traffic_aware_waypoint_env \
    --traffic-density low \
    --episodes 50 \
    --output-dir out/traffic_aware_low

# Train with high traffic
python -m training.rl.traffic_aware_waypoint_env \
    --traffic-density high \
    --episodes 100 \
    --output-dir out/traffic_aware_high
```
