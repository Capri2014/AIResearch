# Daily Notes: 2026-03-18

## Pipeline PR #1: Traffic-Aware Waypoint Environment

### Summary
Added traffic-aware waypoint environment that extends the kinematic environment with dynamic traffic obstacles, bridging the gap between simple kinematic training and real CARLA scenarios.

### Changes

#### Created: `training/rl/traffic_aware_waypoint_env.py`

**TrafficVehicle**: Dynamic traffic vehicle class
- Path-following behavior along predefined waypoints
- Position, heading, speed tracking
- Update method for kinematic movement

**TrafficAwareWaypointConfig**: Extended configuration
- Traffic density levels: NONE, LOW, MEDIUM, HIGH
- Number of static/dynamic obstacles
- Traffic speed range and spawn margins
- Collision and near-collision penalties

**Traffic Generators**:
- `generate_straight_traffic()`: Same/opposite direction traffic
- `generate_cross_traffic()`: Intersecting traffic
- `generate_turn_traffic()`: Turning vehicles at intersections
- `generate_static_obstacles()`: Static obstacle placement

**Collision Detection**:
- `check_collision()`: Circle-based collision between vehicles
- `check_near_collision()`: Proximity detection

**TrafficAwareWaypointEnv**: Main environment class
- Extends KinematicWaypointEnv with traffic
- State includes ego vehicle + traffic positions + obstacles
- Traffic-aware rewards: collision penalty, near-collision penalty
- Supports all traffic density levels

**RL Training**:
- `train_traffic_aware()`: Training loop with simple MLP policy
- Policy gradient updates
- Tracks success rate, collision rate

### Testing Results
```
Smoke test (5 steps): ✓
- State shape: (47,)
- Step rewards: -0.24 to -0.26

Training test (20 episodes, medium traffic): ✓
- Mean reward: -36.29
- Success rate: 0%
- Collision rate: 10%
```

### Usage
```bash
# Smoke test
python -m training.rl.traffic_aware_waypoint_env --test

# Train with low traffic
python -m training.rl.traffic_aware_waypoint_env \
    --traffic-density low \
    --episodes 50 \
    --output-dir out/traffic_aware_low

# Train with high traffic
python -m training.rl.traffic_aware_waypoint_env \
    --traffic-density high \
    --episodes 100 \
    --output-dir out/traffic_aware_high
```

### Architecture
```
KinematicWaypointEnv
    ↓
+ Traffic Vehicles (dynamic)
    ↓
+ Static Obstacles
    ↓
+ Collision Detection
    ↓
+ Traffic-Aware Rewards
    ↓
TrafficAwareWaypointEnv
```

## Pipeline PR #2: PyTorch SSL Pretraining Pipeline

### Summary
Implements PyTorch SSL pretraining pipeline for Waymo driving data with temporal contrastive learning. This bridges the gap between Waymo episodes (PR #1) and waypoint BC training.

### Changes

#### Created: `training/pretrain/waymo_ssl_dataset.py`
- `WaymoTemporalPairDataset`: Creates temporal frame pairs (anchor at t, positive at t+Δt)
- `collate_temporal_pairs()`: Batch collation with stacked tensors for speed, yaw, waypoints
- `create_waymo_ssl_dataloader()`: Factory function for common configurations
- Supports configurable delta_t_range (default: 0.5-2.0 seconds)
- Creates stub synthetic data when episode directory is unavailable

#### Created: `training/pretrain/train_waymo_ssl.py`
- `WaymoSSLConfig`: Configuration dataclass for all training parameters
- `SimpleEncoder`: CNN encoder with ResNet backbone (resnet34/50, efficientnet_b0)
- Projection head with 128-dim embedding output
- `temporal_info_nce_loss()`: Temporal contrastive loss
- Full training loop with checkpointing and metrics logging
- Added `--test` flag for easy smoke testing

#### Modified: `training/episodes/waymo_episode_dataset.py`
- Fixed `episode_dir` type to accept both str and Path
- Added `_create_stub_episodes()` for synthetic data generation
- Returns flat dict format: episode_id, t, speed_mps, yaw_rad, camera_paths, future_waypoints

#### Created: `training/pretrain/__init__.py`: Module exports with lazy imports

### Testing Results
```
Smoke test (5 steps, --test flag): ✓
- Loss: ~2.08
- Encoder saved to out/waymo_ssl_test/encoder_final.pt

Full test (10 steps): ✓
- Stub data: 2970 temporal pairs from 250 frames
- Loss converges appropriately
```

### Usage
```bash
# Run SSL pretraining with default settings
python -m training.pretrain.train_waymo_ssl \
    --episode-dir /path/to/waymo/episodes \
    --batch-size 32 \
    --num-steps 1000

# Quick smoke test (NEW!)
python -m training.pretrain.train_waymo_ssl --test

# With custom encoder and longer delta_t range
python -m training.pretrain.train_waymo_ssl \
    --encoder-type resnet50 \
    --delta-t-min 1.0 \
    --delta-t-max 3.0 \
    --batch-size 16 \
    --out-dir out/waymo_ssl_resnet50
```

### Architecture
```
Waymo episodes → WaymoTemporalPairDataset → temporal InfoNCE → encoder checkpoint
```

The encoder checkpoint can then be loaded by the waypoint BC model for transfer learning.

## Pipeline PR #4: Traffic-Aware BC Evaluation

### Summary
Created evaluation script for BC policies in traffic-aware scenarios, providing baseline metrics and bridging BC (PR #3) with RL refinement.

### Changes

#### Created: `training/rl/traffic_aware_eval.py`

**TrafficAwareBCEvaluator**: Main evaluation class
- `evaluate_random_policy()`: Baseline random policy evaluation
- `evaluate_waypoint_policy()`: Waypoint-following policy evaluation
- Metrics tracked: success rate, collision rate, near-miss rate, mean reward, mean steps, mean progress

**Features**:
- Supports multiple traffic densities: none, low, medium, high
- BC model integration (optional via `--test-bc --bc-checkpoint`)
- JSON output with per-episode details

### Testing Results
```
Smoke test (5 episodes, low density): ✓
- Random policy: 0% success, 0% collision
- Waypoint policy: 0% success, 0% collision

Medium density test (20 episodes): ✓
- Random policy: 0% success, 20% collision
- Waypoint policy: 0% success, 5% collision
```

### Usage

```bash
# Quick smoke test
python -m training.rl.traffic_aware_eval --test

# Medium density evaluation
python -m training.rl.traffic_aware_eval \
    --traffic-density medium \
    --num-episodes 50 \
```
