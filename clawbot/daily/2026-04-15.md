### Created File: `training/sft/postprocess_waypoints.py`

- **Purpose**: Post-process waypoint predictions with kinematic constraints and smoothing
- **Features**:
  - Velocity/acceleration limits (`apply_velocity_limits`, `apply_acceleration_limits`)
  - Temporal smoothing: EMA (`smooth_waypoints_ema`) and Gaussian (`smooth_waypoints_gaussian`)
  - Trajectory validation (`validate_waypoints`): reachability, feasibility checks
  - Speed profile generation: constant, trapezoidal, adaptive (`generate_speed_profile`)
  - CLI: `--predictions`, `--output`, `--max-velocity`, `--max-acceleration`, `--smoothing`
  - Schema-compatible output for downstream CARLA integration

### Usage

```bash
# Post-process waypoint predictions
python training/sft/postprocess_waypoints.py \
    --predictions waypoints.json \
    --output processed.json \
    --max-velocity 10.0 \
    --max-acceleration 3.0 \
    --smoothing 0.3

# Validate trajectories
python training/sft/postprocess_waypoints.py \
    --predictions waypoints.json \
    --validate \
    --output validated.json
```

## Pipeline PR #1: Model Inference API (5:30am PT)

**Task**: Create exactly 1 commit + PR with substantive progress on the core coding pipeline.

### Created File: `training/inference/model_inference.py`

- **Purpose**: Unified inference API for running single forward passes through pipeline models
- **Features**:
  - `WaypointInferenceAPI`: Unified interface for SSL, waypoint BC, and RL refinement stages
  - `SSLEncoderInference`: SSL encoder embeddings from images
  - `WaypointBCInference`: Waypoint predictions from observations
  - `RLRefinementInference`: RL delta refinement: `final = sft + delta_scale * delta`
  - CLI: `--checkpoint`, `--stage`, `--input`, `--output`, `--find-latest`
  - Automatic checkpoint discovery: `--find-latest` finds latest model
- **Output**: JSON predictions with waypoints, speeds, progress, or SSL embeddings
- **Schema**: Compatible with downstream pipeline (CARLA, visualization, eval)

### Usage

```bash
# Run inference on trained checkpoint
python training/inference/model_inference.py \
    --checkpoint out/waypoint_bc/final.pt \
    --input observation.npy \
    --output predictions.json

# Auto-find latest checkpoint
python training/inference/model_inference.py \
    --stage waypoint_bc \
    --find-latest \
    --output predictions.json

# RL refinement stage (SFT + delta)
python training/inference/model_inference.py \
    --stage rl_refinement \
    --sft-checkpoint out/waypoint_bc/final.pt \
    --rl-checkpoint out/rl/best_reward.pt \
    --delta-scale 0.5
```
