### Created File: `training/inference/model_inference.py`

- **Purpose**: Unified inference API for running single forward passes through pipeline models
- **Features**:
  - `WaypointInferenceAPI`: Unified interface for SSL, waypoint BC, and RL refinement stages
  - `SSLEncoderInference`: SSL encoder embeddings from images
  - `WaypointBCInference`: Waypoint predictions from observations
  - `RLRefinementInference`: RL delta refinement: `final = sft + delta_scale * delta`
  - CLI: `--checkpoint`, `--stage`, `--input`, `--output`, `--find-latest`
  - Automatic checkpoint discovery: `--find-latest` finds latest model
- **Output**: JSON predictions with waypoints, speeds, progress, or SSL embeddings
- **Schema**: Compatible with downstream pipeline (CARLA, visualization, eval)

### Usage

```bash
# Run inference on trained checkpoint
python training/inference/model_inference.py \
    --checkpoint out/waypoint_bc/final.pt \
    --input observation.npy \
    --output predictions.json

# Auto-find latest checkpoint
python training/inference/model_inference.py \
    --stage waypoint_bc \
    --find-latest \
    --output predictions.json

# RL refinement stage (SFT + delta)
python training/inference/model_inference.py \
    --stage rl_refinement \
    --sft-checkpoint out/waypoint_bc/final.pt \
    --rl-checkpoint out/rl/best_reward.pt \
    --delta-scale 0.5
```
