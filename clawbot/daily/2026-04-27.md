## Pipeline PR #5: RL after SFT - Waypoint Delta Policy (4:30pm PT / 7:30pm ET)

- **Created: `training/rl/rl_after_sft_e.py`** (~480 lines)
  - `RLAfterSFTConfig`: Configuration dataclass
  - `ToyWaypointKinematicsEnv`: Toy car-like environment consuming waypoints
    - Bicycle model kinematics (pure pursuit steering)
    - Reset to random start + target ahead
    - `_compute_ideal_wp()`: Ideal waypoints as linear interpolation
    - `_get_obs()`: 5-dim state + waypoints + target relative
    - `step()`: Pure pursuit, bicycle model kinematics, reward = -dist_to_target
  - `WaypointDeltaPolicy`: PPO policy with dual head
    - SFT waypoint head (frozen typically) + residual delta head (learned)
    - `get_action()`: Samples with exploration noise
    - Value head for baseline
  - `PPOAgent`: RL agent
    - `get_action()`: Forward pass, collect observations
    - `store_reward()`: Rollout buffer
    - `compute_gae()`: GAE advantage estimation
    - `update()`: PPO value + entropy loss
  - `train()`: Training loop with multi-env rollouts, metrics, checkpointing
  - Outputs: `out/<run_id>/checkpoint.pt` + `metrics.json` + `train_metrics.json`

  - 10 updates, 4 parallel envs
  - Best reward: -6.892 (improving from -10.3)
