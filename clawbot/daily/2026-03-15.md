## Pipeline PR #5: PPO Delta-Waypoint Training with SFT Initialization

### Summary
Created PPO training script for residual delta-waypoint learning after SFT. Implements Option B from the RL-after-SFT roadmap where the action space is waypoint deltas.

### Changes

#### New File: `training/rl/ppo_delta_waypoint_trainer.py`
- **PPODeltaConfig**: Configuration dataclass for PPO training
- **ResidualDeltaHead**: MLP that predicts delta corrections to SFT waypoints
- **PPODeltaPolicy**: PPO policy network for delta-waypoint learning
- **SFTWaypointModelStub**: Stub SFT model for testing without checkpoint
- **train_ppo_delta_waypoint()**: Main training loop with GAE advantages
- Supports loading SFT checkpoint via `--sft-checkpoint` flag
- Outputs `metrics.json` and `train_metrics.json` to out/ directory

### Architecture
```
final_waypoints = sft_waypoints + delta_head(z)
```
- SFT model stays frozen (or uses stub if no checkpoint)
- Delta head learns corrections via PPO
- Supports optional SFT checkpoint loading via bc_checkpoint_loader

### Usage
```bash
# Run with stub SFT model
python -m training.rl.ppo_delta_waypoint_trainer \
    --out-dir out/ppo_delta_waypoint_001 \
    --episodes 50 \
    --seed 42

# With SFT checkpoint
python -m training.rl.ppo_delta_waypoint_trainer \
    --sft-checkpoint out/bc/model.pt \
    --out-dir out/ppo_delta_from_bc \
    --episodes 100
```
